# Анализ алгоритма дистанции Redmi Watch 5 Lite

Данные сняты 2026-09-14 из поминутного дампа файлов дневной статистики часов
(протокол Xiaomi protobuf, поля minute: steps 14-bit + distance 16-bit, raw × 100 = см).
Дамп: 12 367 минут, из них 219 активных минут с шагами и дистанцией.
Профиль юзера: рост 179 см, муж. Формула приложения: шаг × (рост × 0.415) = 74.2 см.

## Выводы

1. **Часы используют адаптивную длину шага** (по акселерометру запястья), не статичную
   формулу: 70–81 см в зависимости от движения. Разброс внутри диапазона ±6.7 см.
2. **Личный шаг юзера на ходьбе (100–120 шаг/мин): 76.3 см** — измерено, не из формулы.
   Формула приложения (74.2) расходится всего на ~3% — калибровка формулы не нужна.
3. Расхождение «часы vs телефон» по дистанции вызвано в первую очередь разным числом
   шагов (разные сенсоры и пороги), а не формулами длины шага.
4. Часы отдают дистанцию поминутно — приложение может показывать в прогулках фактический
   метраж часов вместо оценки шаг × длина.
